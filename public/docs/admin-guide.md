# Home Setup Solutions - Admin Guide

## Overview

This guide covers the administrative features of the Home Setup Solutions platform. Admin access is required to use these features.

---

## Accessing the Admin Panel

1. Go to the website and click **"Customer Login"** or **"Staff Login"**
2. Sign in with your admin credentials
3. You'll be redirected to the **Admin Dashboard**

---

## Dashboard Tabs

The admin dashboard has four main sections:

### 1. Customers Tab

**Viewing Customers**
- Access the Customers tab to view all customer records
- See contact information, service history, and notes
- Customer data is displayed in a searchable table

**Customer Search**
- Use the search bar to find customers by:
  - Name
  - Email
  - Phone number

**Customer Details**
- Click on any customer row to view their full profile
- See appointment history
- Add or edit customer notes

---

### 2. Bookings Tab

**Viewing Appointments**
- All scheduled appointments are listed with:
  - Customer name
  - Service type
  - Date and time
  - Status
  - Address

**Appointment Statuses**
| Status | Meaning |
|--------|---------|
| Pending | Awaiting confirmation |
| Confirmed | Ready to proceed |
| Completed | Service finished |
| Cancelled | Appointment cancelled |

**Managing Appointments**
- Click on any appointment to:
  - Update status
  - Add notes
  - Reschedule
  - View customer details

**Filtering**
- Filter appointments by:
  - Date range
  - Status
  - Service type

---

### 3. Payments Tab

**Payment Overview**
- View all transactions with status indicators:
  - ✅ Paid
  - ⏳ Pending
  - ⚠️ Overdue

**Recording Payments**
- Mark invoices as paid when payment is received
- System tracks:
  - Payment method
  - Payment date
  - Amount

**Reports**
- Export payment data for accounting
- View revenue summaries
- Track outstanding balances

---

### 4. Phone Tab

**Call Logs**
- View incoming and outgoing call history
- Each log shows:
  - Phone number
  - Call direction (inbound/outbound)
  - Timestamp
  - Duration
  - Associated customer (if known)

**Call Notes**
- Add notes to any call record
- Track conversation details
- Set follow-up reminders

**Customer Linking**
- Calls are automatically linked to customer profiles when phone numbers match
- Manually link calls to customers if needed

---

## User Roles

The system supports three user roles:

| Role | Access Level |
|------|--------------|
| Admin | Full access to all features |
| Staff | Limited access (bookings, customers) |
| Customer | View-only for own data |

## Troubleshooting

**Can't access admin panel?**
- Verify your account has admin role
- Try signing out and back in
- Contact system administrator

**Data not loading?**
- Check your internet connection
- Refresh the page
- Clear browser cache

**Need to add a new admin?**
- Contact the system administrator
- New admins must be assigned the role in the database
